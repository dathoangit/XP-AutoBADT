Xuất PDF tổng hợp CLS từ danh sách mã hồ sơ

Phiên HIS Chưa có token

Mở tab 172.16.16.17:2382 và đăng nhập. Extension sẽ tự lấy token.

Luồng xuất

Hoặc dùng file Excel bên dưới

Loại phiếu

Có tiền tố: tiền tố_mã nhân viên_Tên NB_CCCD.pdf. Để trống tiền tố, mã nhân viên hoặc CCCD thì bỏ qua phần đó. Nếu mã nhân viên có dấu -, chỉ lấy phần sau dấu -. Có chữ "lớp" thì bỏ chữ đó, ví dụ lớp 9A thành 9A. Đầy đủ CLS và phiếu KSK dùng cùng cách đặt tên khi Excel có các cột này. Nhập tay hoặc Excel chỉ có mã hồ sơ thì file là mã hồ sơ.pdf.

Chưa chọn file

Mỗi lần xuất đều hỏi thư mục lưu PDF. Hồ sơ đã có file PDF trong thư mục sẽ được bỏ qua.

Giữ side panel mở khi xuất. Bắt PDF thật khi preview load (CDP). Fallback: canvas đã vẽ. Có thể thấy banner debugger tạm thời.
